# BowlingGame

A C++ console application to calculate and manage Bowling game scores with object-oriented design, exception handling, and unit tests.

## Features

- Object-oriented design with Player, Frame, and Game classes.
- Supports full Bowling score calculation:
    - Strike
    - Spare
    - Open Frames
- Handles invalid inputs with exception handling.
- Handles invalid inputs with exception handling.
- CMake based cross-platform build system.
- Run with console interface.

## Build and Run instruction

- Download or clone the git repo: https://github.com/nidhi1711996/BowlingGame
- Create a build dir: mkdir build
- Nevigate to build dir: cd build
- Build and Run with CMake with these steps: 
    - cd build
    - cmake ..
    - make
    - ./BowlingGame
